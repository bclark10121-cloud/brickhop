# Brickhop v0.3.0

Look and sound. Toy box blocks, a wind-up beetle, a toy meadow and real music. The name stays Brickhop, now in its own title font.

## Five minute test

1. The start screen shows the toy meadow, toy blocks and the new Brickhop title. "Pixelland" plays.
2. Press Play. "Carefree" plays in the level, a different track from the start screen.
3. The ground, bricks, coin blocks, Sprout block and pipes are glossy toy pieces.
4. The purple wind-up beetles walk with their legs moving. Stomp one and it goes flat with dizzy eyes.
5. Run right and watch the meadow scroll slower than the blocks.
6. The pipe you can go down has a small bouncing arrow over it.

## New in this version

- Blocks, ground and pipes cut from a Gemini block sheet in the game's style thread.
- The walker is now a wind-up beetle from Gemini: two walk frames and a squashed frame.
- A toy meadow background from Gemini, repeating and scrolling at 60 percent speed.
- Music from Patch.gg: "Pixelland" (start screen) and "Carefree" (play) by Kevin MacLeod, CC BY 4.0, looped and level-matched.
- Title font Lilita One on the start screen, the game page and The Game Shelf. The name Brickhop stays.

## Shared kit

Built with kit 1.16.0. Godot 4.7.2.

## Install

Installs over 0.2.0 and keeps your saves.

## Full test checklist

1. Music loops with no gap on both tracks.
2. Music and Sound sliders in Settings change the new tracks.
3. Upright on a phone, the meadow still fills the sky behind the level.
4. The bot reaches the flag on Breezy, Standard and Classic (HOP check).

## Not tested

Real phones, the Retroid, a real Xbox controller and touch by hand. Coin pickups and block bumps still use the starter sounds.
