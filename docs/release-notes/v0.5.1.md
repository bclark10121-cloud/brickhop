# Brickhop v0.5.1

The same jumps as 0.5.0, now run by the shared studio kit.

## Five minute test

1. Run right and jump a few gaps. The jumps should feel exactly like 0.5.0: the same height, the same fall, the same landing spot on screen.
2. Tap Jump for a short hop, then hold it for a full jump. Both should match 0.5.0.
3. Stomp a beetle while holding Jump. The bounce goes high. Stomp one without holding Jump. The bounce is short.
4. Run off a ledge and press Jump just after you leave it. The jump still works.
5. Press Jump just before you land. The jump happens on landing.

## What changed

Under the hood
- Run, jump and fall now come from the shared kit block K1 (kit 1.19.0, BC 2026-11-20: "work on the kit sprint first"). The kit was pulled out of this game and Home by Dusk.
- Every number is the same as 0.5.0. Brickhop passes them to the kit as its own tuning.
- From now on, a jump fix lands in one place in the kit and reaches every platformer that uses it.

Also from the newer kit
- No 60 frame cap on any device (kit 1.17.1, G6.20).
