# Brickhop v0.1.0

The gray box test build of 1-1 Toybox Meadow. Plain shapes, stand-in sound. It tests how the running and jumping feel.

## Five minute test

1. Press Play, pick slot 1 and run right. Tap jump for a small hop and hold it for a high jump.
2. Hold Run (Shift, X or the Run button) and jump a gap. The jump goes further.
3. Bump the yellow blocks from below for coins. The green block gives a Sprout.
4. Jump on a purple walker to stomp it. Walk into one and see a few coins drop.
5. Fall into a pit. You land back on the last ledge.
6. Press down on the green pipe with the arrows to reach the secret room.
7. Touch the flag and see your time.

## New in this version

- 1-1 Toybox Meadow: coin blocks, a Sprout block, bricks, a hidden block, coins, three star coins, walkers, a checkpoint, a secret room and the flag with a best time.
- Soft fail: no lives and no game over. A hit or a fall costs coins.
- Breezy, Standard and Classic difficulty. Run set to Hold, Toggle or Always.
- Touch buttons, Xbox controller and keyboard.

## Shared kit

Built with kit 1.16.0. Godot 4.7.2.

## Install

The first version. Nothing to install over.

## Full test checklist

1. The start screen shows the hopper bouncing between brick rows.
2. Settings has Difficulty and Run.
3. Hit from a walker on Breezy costs nothing. On Standard 5 coins. On Classic 10.
4. The Menu has Restart level.
5. Turn the phone upright. The level still fills the screen.
